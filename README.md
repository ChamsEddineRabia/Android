# Streamloom Android

An original Android WebView shell for the Streamloom UI prototype. It does not copy StreamLens source, branding, or media.

## Build

A GitHub Actions workflow runs on each push to `main` and can also be started manually. It produces `app/build/outputs/apk/debug/app-debug.apk` as a downloadable artifact named `streamloom-debug-apk`.

This prototype has illustrative playlist, guide, profile, and playback UI. It does not yet parse real playlists or play streams.
